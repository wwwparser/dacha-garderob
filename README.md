# Дачный гардероб

Статический HTML-каталог мужской одежды и обуви для дачи на осень и зиму.

50 моделей Wildberries: по 10 вариантов обуви, курток, брюк, шапок и перчаток. В каждой категории вручную выбран топ-3. Есть фотографии товаров, плюсы, ограничения, сценарии использования и короткие цитаты из отзывов с датой и оценкой покупателя.

## Данные и ограничения

Сбор: 7 октября 2026 года. Характеристики и фотографии получены напрямую из статических карточек WB; отзывы — из feedbacks API. Цитаты относятся именно к артикулу в карточке каталога. Общая оценка и число оценок могут охватывать объединённые цвета, размеры и варианты. Фотографии принадлежат правообладателям товаров и используются для идентификации моделей со ссылкой на продавца.

Поиск и динамические цены WB возвращали HTTP 403 при прямом подключении из России. Текущие цены и наличие не подтверждены. Поле `budget` — субъективный предел разумной покупки, а не цена WB. Без размеров пользователя подборка не подтверждает наличие подходящего размера. Более дорогие модели включены только как альтернативы для покупки со скидкой в пределах обозначенного бюджета.

Поисковая выдача собиралась через XMLRiver. Найдены пять релевантных YouTube-видео. Получение субтитров и аудио заблокировано проверкой YouTube; в сайте оставлены три дополнительные ссылки, содержание роликов не выдано за просмотренное. Прочитаны материалы Nordman об ЭВА и Гетсиз о покрытых зимних перчатках.

Топ-3 — авторский выбор по пригодности для разных дачных задач, материалам и содержательным отзывам. Это не лабораторный рейтинг и не доказанная сортировка по текущей цене. Источники характеристик доступны в подробностях каждой модели, отзывы — по ссылке на карточку WB.

## Просмотр

Откройте `index.html` или запустите `python -m http.server 8765` из корня проекта. Внешние библиотеки и сервер для работы каталога не требуются.

## Файлы

- `index.html`, `style.css`, `app.js` — сайт и интерфейс.
- `catalog.js` — подготовленные данные и источники; здесь удобно редактировать рекомендации.
- `assets/products/` — 50 проверенных фотографий товаров.
- `src/build_catalog.py` — авторские заметки, выбор топ-3, сборка каталога.
- `src/research.py`, `src/services/xmlriver_client.py` — поиск источников через XMLRiver.
- `src/collect.py`, `src/services/wb_service.py` — карточки WB и отзывы, прямое соединение без прокси.
- `src/verify.py` — проверка цитат, категорий, фотографий и интерфейса.

## Повторный сбор на машине Юрия

Скрипты используют установленный навык `~/.codex/skills/wildberries`. Зависимости уже установлены: requests, python-dotenv; для проверки — Pillow и Playwright с Chrome. Ключи XMLRiver задаются в `.env` по шаблону `.env.example`. `.env`, сырые ответы, отзывы с техническими идентификаторами и скриншоты не публикуются.

```powershell
$env:PYTHONUTF8='1'
python src/research.py
python src/collect.py
python src/build_catalog.py
python src/verify.py
```

Повторный сбор использует кэш. Выбор моделей и смысловые заметки редактируются вручную после чтения новых отзывов; автоматический пересбор не означает обновления рекомендаций.

## Проверено

50 уникальных артикулов, 10 товаров и три ранжированных выбора в каждой категории; все 50 моделей имеют текстовые отзывы именно своего артикула. Каждая опубликованная цитата сверена с исходным отзывом, датой и оценкой; суммарно не более 25 слов прямых цитат на карточку. Все 50 изображений валидны. Проверены категории, топ-3, поиск, пустое состояние, сортировка, подробности, закрытие по Escape и кнопке, отсутствие ошибок JavaScript и горизонтального переполнения на телефоне.
