# Дачный гардероб

[Открыть каталог](https://wwwparser.github.io/dacha-garderob/)

Статический HTML-каталог: 70 моделей Wildberries, по 10 сапог, курток, брюк, шапок, перчаток, галош и сабо/тапочек. В каждой категории вручную выбран топ-3. Есть фотографии, назначение, плюсы и ограничения, цитаты покупателей, цены и доступные размеры.

## Проверка наличия

7 октября 2026 года каждый артикул проверен на отдельной странице WB. Куртки и брюки имеют предложения для **54, 56, 58**, сапоги/галоши/сабо — **43, 44, 45**. Сдвоенные размеры учитываются по маркировке производителя, ростовка показана в подробностях. Для шапок и перчаток показаны доступные варианты: размер одежды не означает размер головы или ладони.

Цена — `price.product` доступного предложения / 100, без скидки WB Кошелька. Если варианты стоят по-разному, показана цена «от», в подробностях — цена каждого. Это снимок предложения к заказу для региона, выбранного в браузере, а не постоянно обновляемый складской остаток. Время каждой проверки указано в МСК. Цена, остаток и доставка могут измениться; наличие размерной маркировки не доказывает правильную посадку.

ShoesKomfort включены по примеру пользователя: текущая цена 1 672 ₽ отличается от прежней цены на скриншоте. Летние модели без утепления и куртка без утеплителя явно обозначены. Температурные обещания продавцов не выданы за результаты испытаний.

## Источники

Характеристики, фотографии и отзывы получены напрямую через API на основе установленного навыка `wildberries`. Динамические запросы поиска/цен/остатков возвращали 403; для них использована нормальная навигация в существующем Chrome через `browser-bridge` и чтение фактических ответов сайта. Запросы WB выполнялись без прокси. Корзина и заказы не изменялись. Cookies, заголовки авторизации и адрес доставки в публичные файлы не записывались.

69 моделей имеют короткие цитаты именно выбранного артикула с датой и оценкой автора. У одного дополнительного варианта сабо текстовых отзывов данного артикула в доступной выгрузке нет: это явно указано, отзывы соседних артикулов не перенесены. У всех 21 моделей топа есть точные отзывы. Общий рейтинг/счётчик WB может объединять варианты. Отбор и тексты авторские; рейтинг не является лабораторным тестом.

Первоначальная поисковая выдача собиралась через XMLRiver. Прочитаны материалы Nordman об ЭВА и Гетсиз о перчатках. YouTube-ссылки — дополнительные материалы: получение субтитров и аудио было заблокировано, содержание роликов не используется как доказательство.

## Просмотр и обновление

Сайт работает без зависимостей: откройте `index.html` или запустите `python -m http.server 8765 --bind 127.0.0.1`.

Исследовательские скрипты используют `requests`, `python-dotenv` и локальные навыки `wildberries`/`browser-bridge`. Проверка UI использует установленный Playwright, Chrome и Pillow.

1. Открыть отдельную фоновую вкладку WB в сессии Browser Bridge `dacha-stock`.
2. `python src/refresh_live.py` — собрать поисковые ответы. Скрипт возобновляет сбор из `data/live`; для свежего исследования удалить конкретные устаревшие файлы кеша.
3. `python src/prepare_live_catalog.py` — отфильтровать размеры/цены, выбрать 10 различных групп на категорию и загрузить характеристики/отзывы.
4. `python src/verify_live_stock.py` — проверить каждый выбранный артикул. Кеш `verified_<id>.json` пригоден только для того же сеанса; перед новым обновлением очистить эти файлы.
5. Пересмотреть авторские тексты и топы в `src/live_notes.py`, затем `python src/build_live_catalog.py`.
6. При работающем локальном сервере: `python src/verify.py` — проверка размеров, цен, цитат, изображений и интерфейса на десктопе/телефоне.
7. Закрыть вкладку задачи и опубликовать статические файлы в ветку `main`.

`catalog.js` содержит публичные сведения. Сырьё `data/`, `.env` и логи исключены из Git. Ключи не хардкодятся. Старые `src/build_catalog.py` и `src/research.py` сохранены как инструменты первого исследования; для актуального каталога используется `build_live_catalog.py`.
